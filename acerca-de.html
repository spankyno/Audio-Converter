Acerca de esta aplicación

Un convertidor de audio gratuito, rápido y completamente privado que funciona en tu navegador.

1 Cómo funciona (paso a paso)

  1. 1

    Seleccionas tus archivos

    Arrastra uno o varios archivos de audio o vídeo (o haz clic para elegirlos). Se leen directamente desde tu dispositivo.

  2. 2

    Eliges formato, calidad y metadatos

    Escoges el formato de salida, el nivel de calidad/bitrate y, si quieres, rellenas título, artista, álbum, año, género y comentario.

  3. 3

    La conversión ocurre en tu navegador

    Se descarga una versión de FFmpeg compilada a WebAssembly y se ejecuta en un hilo de fondo de tu pestaña. El archivo nunca sale de tu ordenador.

  4. 4

    Descargas el resultado

    Cuando termina, puedes descargar cada archivo individualmente o todos juntos. Al cerrar la pestaña, todo desaparece de la memoria.

2 Stack tecnológico

FFmpeg.wasm

Motor de conversión de código abierto (el mismo que usan VLC y muchos editores profesionales) compilado a WebAssembly para ejecutarse en el navegador.

HTML5 + JavaScript moderno + Tailwind CSS

Interfaz ligera, responsive, con modo claro/oscuro y sin frameworks pesados. Todo el código se ejecuta en el cliente.

Web Workers

La conversión se realiza en un hilo de fondo para que la interfaz no se congele durante el proceso.

3 Compromiso de privacidad

  • Cero subidas. Tus archivos de audio o vídeo nunca se envían a ningún servidor.
  • Procesamiento local. Toda la conversión ocurre dentro de tu navegador usando WebAssembly.
  • Sin almacenamiento. Al cerrar la pestaña o recargar, los archivos desaparecen de la memoria. No se guardan copias.
  • Sin cuentas ni tracking de archivos. No es necesario registrarse. No se analiza el contenido de tus audios.
  • Motor verificado. El motor de conversión se descarga una vez desde un CDN y se comprueba con una huella SHA-384 antes de ejecutarse; el resto del código se sirve desde este mismo sitio.
  • Analítica de visitas mínima. Estadísticas de visita propias (IP, navegador, página); nunca tus archivos. Consulta la política de privacidad.

2. Datos que recogemos
